Ты работаешь в ветке `feature/EPIC-N`, она уже выбрана. Ветки не переключай. Никаких `push`, `merge`, `rebase`, `reset`, `stash`, `--amend`, `--no-verify`.

## Задача

1. Прочитай файл задачи целиком. Делаешь ровно «Что сделать», в местах из «Где». «Требования из плана» обязательны. «Чего не делать» не делаешь.
2. Доработка: в задании есть вердикт тестировщика, а в файле задачи — «История доработок». Исправь то, что в последнем пункте истории, остальное не трогай.
3. PLAN.md не читай. Чего-то не хватает в файле задачи или он противоречит коду — не угадывай, верни вопрос.

## Правила

- Правила CLAUDE.md обязательны: без комментариев, читаемость, дизайн API, официальные пакеты Nest, импорты.
- Если правило скилла `nestjs-best-practices` расходится с CLAUDE.md или файлом задачи — прав проект.
- По коду сначала `graphify query "<вопрос>"`, потом grep и чтение файлов.
- API библиотек — через `pnpm exec ctx7` (`.claude/rules/context7.md`) и ссылки из раздела «Документация».
- Новые зависимости — только если они названы в файле задачи. Иначе вопрос.
- Приёмочные тесты из `tasks/EPIC-N/TESTS.md` не меняй. Тест кажется неверным — верни вопрос. Свои дополнительные тесты писать можно.
- Файлы в `tasks/` не меняй и не коммить.

## Проверки перед коммитом

1. `pnpm lint`.
2. `pnpm --filter <пакет> check-types` для каждого затронутого пакета, если у пакета есть такой скрипт.
3. `pnpm --filter <пакет> exec vitest run <файлы>` — приёмочные unit-тесты этой задачи из `TESTS.md` и твои тесты.

Ошибки линтера и типов в приёмочных тестах других задач эпика не считаются: их код ещё не написан. Все остальные ошибки исправь.

## Коммит

- Файлы явными путями (`git add <путь>`), сообщение по `.claude/skills/git-commit/SKILL.md`, разделы 3 и 4. Без `Co-Authored-By` и упоминаний ИИ.
- Можно несколько коммитов, если в задаче несколько логических изменений.
- Упал хук pre-commit на твоём коде — исправь и закоммить снова. На чужом — остановись и верни ошибку.

## Ответ

На русском:

- готово или вопрос;
- коммиты: `git log --oneline <первый твой коммит>^..HEAD`;
- какие проверки запускал и с каким результатом;
- что из задачи не сделано и почему.
