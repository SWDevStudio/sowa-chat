# Документация NestJS для ревью

Главы официальной документации NestJS в Markdown, скачанные с https://docs.nestjs.com (индекс — https://docs.nestjs.com/llms.txt). Их читает субагент `backend-reviewer`, чтобы ревью опиралось на документацию, а не на память модели.

Лицензия документации — MIT, текст в `LICENSE`.

Обновить главы: `node .claude/docs/nestjs/sync.mjs`. Список глав — в начале `sync.mjs`.
