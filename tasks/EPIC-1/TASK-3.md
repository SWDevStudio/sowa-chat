# EPIC-1 / TASK-3. Схема JsonObject с лимитами

Исполнитель: sonnet
Зависит от: TASK-1
Ветка: feature/EPIC-1

## Что сделать

В `protocol` описать типы `JsonValue` и `JsonObject` и zod-схему, которая проверяет, что значение — JSON-объект в пределах лимитов. Этой схемой сервер проверяет `context`, `visitorData` и `payload` кастомных сообщений, а SDK — те же данные в браузере.

Лимиты на сервере задаются в env, поэтому нужны две вещи: схема с лимитами по умолчанию и способ получить схему с другими лимитами.

## Где

- `packages/protocol/src/` — новый файл со схемой, например `json-object.ts`.
- `packages/protocol/src/index.ts` — реэкспорт.

## Требования из плана

Типы:

```ts
type JsonValue = string | number | boolean | null | JsonValue[] | { [key: string]: JsonValue };
type JsonObject = { [key: string]: JsonValue };
```

Правила (значения по умолчанию):

| Правило | По умолчанию | От чего защищает |
|---|---|---|
| форма | сверху объект, значения — только JSON | ломается тип `JsonObject` и слияние по JSON Merge Patch |
| размер объекта в JSON | до 16 КБ | раздувание БД и списка диалогов |
| глубина вложенности | до 5 уровней | переполнение стека при рекурсивной обработке |
| ключей всего, на всех уровнях | до 100 | медленная обработка и раздувание GIN-индекса |
| ключ | до 64 символов: латиница, цифры, `_`, `-`; запрещены `__proto__`, `constructor`, `prototype` | prototype pollution при слиянии объектов |
| строковое значение | до 2 КБ | раздувание отдельных полей |
| массив | до 100 элементов | то же |

Уточнения:
- Размеры считаются в байтах UTF-8: объект — по длине `JSON.stringify`, строка — по длине самой строки.
- Объект верхнего уровня — уровень 1.
- Числа — только конечные: `NaN` и `Infinity` не JSON.
- Ключ `__proto__` из `JSON.parse` становится собственным свойством объекта. Проверять нужно собственные ключи (`Object.keys`).
- Очень глубокий объект не должен ронять проверку переполнением стека: обход останавливается, как только глубина превышена.
- Ошибка говорит, какое правило нарушено и где (путь к ключу).
- SDK импортирует из `protocol` только типы, поэтому `JsonValue` и `JsonObject` экспортируются как типы отдельно от схемы.

## Критерии приёмки

- На каждое правило таблицы есть случай «на границе проходит» и «за границей отклоняется».
- `JSON.parse('{"__proto__": {"x": 1}}')` отклоняется; ключи `constructor` и `prototype` тоже.
- Массив, строка, `null` и число на верхнем уровне отклоняются.
- Объект глубиной 10 000 отклоняется без падения процесса.
- Схема, собранная с другими лимитами, применяет их, а не значения по умолчанию.

## Чего не делать

- Не реализовывать JSON Merge Patch — это задача эпика данных посетителя.
- Не читать env внутри `protocol`: лимиты передаёт тот, кто собирает схему.
