# EPIC-10 / TASK-3. Выпуск, отзыв и генерация ключей

Исполнитель: sonnet
Зависит от: TASK-2
Ветка: feature/EPIC-10

## Что сделать

Команды для serverKey:

1. `key:create --project <имя>` — выпускает новый `sk_` и выводит его один раз. Старые ключи проекта продолжают работать.
2. `key:list --project <имя>` — ключи проекта: `prefix`, дата создания, `last_used_at`, отозван или нет. Без самих ключей.
3. `key:revoke --prefix <prefix>` — отзывает ключ.
4. `key:generate` — печатает новый `sk_` и ничего не меняет в БД. Нужна DevOps, чтобы заранее положить ключ в хранилище секретов и передать его через `SOWA_INIT_SERVER_KEY`.

Выпуск и отзыв — через сервис ключей, события аудита уже есть.

## Где

- Модуль режима `cli` — команды.

## Требования из плана

Ротация serverKey: на время замены активны два ключа. Порядок: `key:create` → новый ключ в секреты админки и деплой → `last_used_at` старого ключа перестал расти → `key:revoke`.

`key:generate` ничего не меняет в базе, только печатает новый ключ.

## Критерии приёмки

- После `key:create` оба ключа проекта проходят проверку.
- После `key:revoke` отозванный ключ не проходит проверку.
- `key:generate` не меняет ни одной строки в БД, а напечатанный ключ проходит разбор по формату.
- Создание и отзыв видны в `audit_log`.

## Чего не делать

- Не делать команды для ключей ботов — это эпик ботов.
