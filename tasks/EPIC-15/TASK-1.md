# EPIC-15 / TASK-1. Метрики HTTP по шаблону маршрута

Исполнитель: haiku
Зависит от: —
Ветка: feature/EPIC-15

## Что сделать

1. `TelemetryInterceptor` — глобальный interceptor в модуле `telemetry`, через который проходит каждый HTTP-запрос.
2. Метрики в общем реестре `prom-client`:
   - счётчик запросов `http_requests_total`;
   - гистограмма длительности `http_request_duration_seconds`.
3. Метки: `zone`, `method`, `route` (шаблон маршрута, например `/v1/visitor/conversations/:id/messages`), `status`.
4. Ответы с ошибкой тоже учитываются, с их статусом.

## Где

- `apps/server/src/telemetry/`.

## Требования из плана

- Внутри один «пайп»: каждый запрос проходит через `TelemetryInterceptor`.
- HTTP: запросы, ошибки и длительность по маршрутам.
- Метки — только значения из ограниченного списка; маршрут — это шаблон, а не настоящий URL с ID. ID диалогов, посетителей и сообщений в метки не попадают: иначе каждое новое значение создаёт новый временной ряд, и память растёт без предела.

## Документация

- https://docs.nestjs.com/interceptors
- https://github.com/siimon/prom-client

## Критерии приёмки

- После запросов к тестовому маршруту с параметром `/:id` с разными ID в `/metrics` один ряд с шаблоном маршрута, а не ряд на каждый ID.
- Запрос, закончившийся ошибкой 400, учтён со `status="400"`.
