# EPIC-16 / TASK-3. Лимиты по IP на новые сессии и неверные токены

Исполнитель: sonnet
Зависит от: TASK-1, TASK-2
Ветка: feature/EPIC-16

## Что сделать

1. Лимит новых анонимных сессий с одного IP: `SOWA_ABUSE_SESSIONS_PER_IP_PER_HOUR`, по умолчанию 100. Применяется к `POST /v1/visitor/session`.
2. Лимит попыток с неверным или поддельным токеном/ключом с одного IP: `SOWA_ABUSE_INVALID_AUTH_PER_IP_PER_MINUTE`, по умолчанию 30. Считаются только неудачные проверки во всех guards (посетитель, оператор, `sk_`). После превышения запросы с этого IP получают 429 до конца окна, даже с верным токеном.
3. `SOWA_ABUSE_ALLOWLIST_CIDRS` — адреса, к которым лимиты по IP не применяются (офис, мониторинг). По умолчанию пусто.
4. `SOWA_ABUSE_ENABLED` (по умолчанию `true`) выключает эти лимиты.

## Где

- `apps/server/src/infra/rate-limit/`.
- Guards посетителя, оператора и `sk_` — учёт неудачных попыток.
- `apps/server/src/infra/config/`, `apps/server/.env.example`.

## Требования из плана

| Переменная | По умолчанию | Что ограничивает |
|---|---|---|
| `SOWA_ABUSE_ENABLED` | `true` | включение защиты |
| `SOWA_ABUSE_SESSIONS_PER_IP_PER_HOUR` | `100` | новых анонимных сессий с одного IP в час |
| `SOWA_ABUSE_INVALID_AUTH_PER_IP_PER_MINUTE` | `30` | попыток с неверным или поддельным токеном с одного IP в минуту |
| `SOWA_ABUSE_ALLOWLIST_CIDRS` | пусто | адреса, которые не блокируются никогда |

- Лимиты по IP касаются только создания новых сессий, неверных токенов и явного флуда и стоят заметно выше остальных: у мобильных операторов и в офисах за одним IP могут сидеть тысячи настоящих пользователей.
- IP в БД не попадает и не отдаётся ни в админку, ни в API.

## Документация

- https://docs.nestjs.com/security/rate-limiting

## Критерии приёмки

- 101-я сессия с одного IP за час — 429 с `Retry-After`.
- 31-я неудачная попытка с одного IP за минуту — 429; удачные попытки счётчик не увеличивают.
- Адрес из allowlist не ограничивается.
- В БД нет IP.

## Чего не делать

- Не делать лимиты по посетителю и блокировки с растущим сроком — это эпик защиты от спама.
