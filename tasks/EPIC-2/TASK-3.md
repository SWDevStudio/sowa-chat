# EPIC-2 / TASK-3. Точка входа с режимами api, worker, migrate, cli

Исполнитель: sonnet
Зависит от: TASK-1, TASK-2
Ветка: feature/EPIC-2

## Что сделать

Один собранный сервер запускается в одном из четырёх режимов, и у каждого режима свой набор модулей.

1. Режим задаётся первым аргументом командной строки: `node dist/main.js api`. Без аргумента или с неизвестным значением процесс завершается с кодом 1 и выводит список режимов.
2. У каждого режима свой корневой модуль:
   - `api` — HTTP-приложение (`NestFactory.create`). Пока без контроллеров; порты и зоны добавит эпик зон API, а сейчас приложение слушает `SOWA_PUBLIC_PORT`.
   - `worker` — приложение без HTTP: создаёт контекст через `NestFactory.createApplicationContext` и завершается с кодом 0. Живым процесс сделает эпик с очередями.
   - `migrate` — приложение без HTTP. Миграции появятся в эпике базы данных, а сейчас режим запускается и сразу завершается с кодом 0.
   - `cli` — приложение без HTTP. Команды появятся в эпике CLI, а сейчас режим запускается и сразу завершается с кодом 0.
3. Общие модули (конфиг) подключаются во всех режимах.
4. Скрипты в `apps/server/package.json`: `start:api`, `start:worker` и аналоги для разработки с `--watch`.

## Где

- `apps/server/src/main.ts`.
- `apps/server/src/` — корневые модули режимов (например, `api.module.ts`, `worker.module.ts`). Старый `app.module.ts` удалить, если он больше не нужен.
- `apps/server/package.json` — скрипты.

## Требования из плана

- Один образ работает в режимах `api`, `worker`, `migrate` и `cli`.
- Режим выбирает набор модулей: `api` подключает `api/*` и `realtime`, `worker` — `jobs`, `bot-hub`, `events`, `builtin-bots`. Сейчас этих модулей ещё нет, но структура должна позволять подключать их к своему режиму.
- `api` без состояния в памяти; `worker` — фоновые задачи.

## Критерии приёмки

- `api` отвечает по HTTP (хотя бы 404 на любой путь).
- `node dist/main.js worker` завершается с кодом 0; HTTP-порт не открыт.
- `migrate` и `cli` завершаются с кодом 0.
- Без аргумента и с `node dist/main.js foo` — код 1 и список режимов в выводе.

## Чего не делать

- Не реализовывать корректную остановку по SIGTERM — это TASK-4.
- Не настраивать несколько портов — это эпик зон API.
