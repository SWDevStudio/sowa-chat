# EPIC-7 / TASK-3. Проверка ответов по схемам

Исполнитель: sonnet
Зависит от: —
Ветка: feature/EPIC-7

## Что сделать

Ответы контроллеров проходят через zod-схемы ответов, и наружу не уходят лишние поля.

1. Глобальный interceptor из `nestjs-zod` (сериализация по схеме ответа) через `APP_INTERCEPTOR`.
2. Схема ответа задаётся у обработчика декоратором из `nestjs-zod`, эта же схема попадает в OpenAPI.
3. Поля, которых нет в схеме, удаляются из ответа. Если ответ не проходит схему (не хватает обязательного поля) — это ошибка сервера: 500 и запись в лог.

## Где

- `apps/server/src/infra/http/`.

## Требования из плана

- Ответы: interceptor прогоняет их через схемы ответов, чтобы наружу не ушли лишние поля. Например, сущность с `key_hash` не должна попасть в ответ целиком.

## Документация

- https://docs.nestjs.com/interceptors
- https://github.com/BenLorantfy/nestjs-zod

## Критерии приёмки

- Тестовый обработчик возвращает объект с лишним полем `secret` — в ответе поля нет.
- Ответ без обязательного поля — 500 `internalError`, в логе ошибка схемы.

## Чего не делать

- Не описывать схемы ответов реальных эндпоинтов — их ещё нет.
