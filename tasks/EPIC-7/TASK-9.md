## Что сделать

Открыть Swagger UI в браузере в development и проверить, что он работает со строгой CSP от `helmet`. В первую очередь проверить директиву `upgrade-insecure-requests` при работе по `http://localhost`: из-за неё браузер может пытаться загрузить ресурсы по `https` и не показать страницу.

Если что-то не работает — решить, как ослабить CSP только для путей Swagger UI в development, и передать решение исполнителю.

## Где

- `http://localhost:9090/docs/public` и остальные документы.

## Требования из плана

- После установки библиотек этапа 0 проверить в браузере Swagger UI со строгой CSP от `helmet`, в первую очередь `upgrade-insecure-requests` при работе по `http://localhost`.

## Документация

- https://helmetjs.github.io/

## Критерии приёмки

- Ручная проверка: Swagger UI открывается и выполняет запросы по `http://localhost`.
- Ручная проверка: в консоли браузера нет ошибок CSP.

## Чего не делать

- Не отключать CSP целиком.
